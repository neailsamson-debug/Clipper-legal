Clipper

Clipper is a personal desktop tool that cuts long videos (stream recordings and podcast episodes) into short vertical clips and uploads them to the YouTube channels of its owner, Samson Neail.

How it uses YouTube

Clipper uses YouTube API Services (the YouTube Data API v3, method videos.insert) to upload finished clips to the owner's own YouTube channels. Videos are uploaded as private first and published by the owner in YouTube Studio. Clipper does not read, store or share any data of other YouTube users.

By using this tool you agree to be bound by the YouTube Terms of Service.
