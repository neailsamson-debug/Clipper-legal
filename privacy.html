Clipper - Privacy Policy

Last updated: 2026-10-23. Back to the Clipper home page

Clipper is a personal desktop application run by Samson Neail ("I", the "developer"). It runs only on the developer's own computer. There is no Clipper server, website account or database: Clipper does not collect data about visitors of this site or about anyone other than the developer.

YouTube API Services

Clipper uses YouTube API Services. By using Clipper you agree to be bound by the YouTube Terms of Service. The Google Privacy Policy applies to the data handled through these services: https://policies.google.com/privacy.

What data Clipper accesses

When the owner signs in with Google, Clipper asks for exactly one permission (OAuth scope):

  • https://www.googleapis.com/auth/youtube.upload - "Manage your YouTube videos": used only to upload videos to the signed-in user's own channel.

Clipper does not read your channel's videos, comments, subscribers, analytics or any personal profile data. The only information it receives from YouTube is the video ID of each video it has just uploaded.

How the data is used and stored

  • The sign-in token (OAuth access and refresh token) is stored in a file on the developer's computer only. It is used only to upload videos to the channel it belongs to.
  • The video IDs of uploaded videos are written to a local log file on the same computer so the developer can find them.
  • The videos, titles and descriptions uploaded are created by the developer. No YouTube user data is cached beyond the video ID log.

Sharing

I do not sell, rent, transfer or share Google user data or YouTube API data with anyone. I do not use it for advertising, and nobody else, human or automated, reads it.

Revoking access and deleting data

  • You can revoke Clipper's access to your Google account at any time at https://myaccount.google.com/permissions.
  • After revoking, delete the local token file (tools/youtube/token_*.json) to remove the stored credentials. If you ask me by email to delete data I hold about you, I will do so within 7 days.
  • Videos already uploaded stay on YouTube until you delete them in YouTube Studio.

Children

Clipper is not directed at children and collects no data from them.
